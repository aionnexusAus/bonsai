# Project 3 — Feijoa (`Acca sellowiana`)

Pineapple guava. Melbourne-hardy evergreen. Solo bonsai only.

## ID

Oval leaves: green above, silvery felt below.

## Role

Solo informal upright / multi-trunk · finished ~60–90 cm · not for elm forest.

## Care (Melbourne)

| Topic | Guidance |
|-------|----------|
| Soil | Same budget free-draining mix as the plan; feijoa tolerates a touch more organic matter |
| Potting | Grow pot first; hard root prune in **September** (evergreen window) |
| Stem prune | Light tip prune year-round; bigger cuts after flower/fruit or with Sep root work |
| Root prune | Sep 2027 first hard session; ~30–40% max first time |
| Training | Wire young wood sparingly; check often |
| Fertilising | Dilute feed spring–early summer (Oct start is good); ease off in heatwaves and winter |

## Phase 0 (Oct 2026)

Label `P3-Feijoa`, harden to outdoor sun, water, dilute feed, tip prune only.
